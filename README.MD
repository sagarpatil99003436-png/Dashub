Health Dataset MLOps Project with DagsHub & DVC
📖 Project Overview
This project is part of my MLOps learning journey. I am learning DagsHub, DVC, Git, and MLflow for the first time by following a Udemy course and practicing with a Health Dataset.

The goal of this project is to understand how modern MLOps tools are used to manage code, datasets, experiments, and machine learning workflows.

🎯 Learning Objectives
Learn Git and GitHub
Learn DVC (Data Version Control)
Learn DagsHub Integration
Learn MLflow Experiment Tracking
Work with a Health Dataset
Build Machine Learning Pipelines
Understand MLOps Best Practices
